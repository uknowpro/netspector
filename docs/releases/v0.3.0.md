## netspector v0.3.0

A compact, project-oriented HTML network diagram replaces the long default report view.

### Network diagrams

- Server, gateway, service, and container symbols with project boundaries and a shared-host area. Symbols represent discovered logical roles, not verified physical devices.
- One node per normalized host, independent of scheme, port, or URL path. Inbound and outbound arrows reuse that node. DNS aliases are not guessed; literal localhost names describe addresses, not physical identity.
- Deduplicated directed edges retain ports, paths, candidates, and source evidence. Configuration-only associations have no arrow; uncertain connections are dashed.
- Orthogonal connectors and protocol/port labels. Drag nodes within their group or use keyboard arrow keys; reset layout, zoom, and export the current diagram as standalone SVG.
- Project/search/direction filters, clickable evidence, and collapsed endpoint/infrastructure lists. Layout changes last for the open page; SVG preserves the current view, not the expandable source inventory.
- Project boundaries follow the nearest scanned package/build manifest. Source apps are not automatically equated with Kubernetes workloads, and Ingress exposure addresses are not treated as client identities.

HTML remains offline and self-contained, with no CDN or discovered-endpoint requests. The graph shows at most 160 nodes and explicitly indicates truncation; project/search filters and the complete grouped tables expose the remainder. JavaScript is required for the diagram; tables remain accessible without it. JSON/CSV findings are preserved; JSON adds `project.roots` with `schema_version: "1"` unchanged.

### Verification and packages

92 unit tests and the Linux/macOS/Windows Python 3.11–3.13 CI matrix cover analysis and graph aggregation. Chrome checks cover filters, host reuse, desktop/mobile layout, drag, keyboard movement, reset, and SVG download. Every extracted native package is smoke-tested outside the checkout, including the multi-project HTML example.

Windows binaries are unsigned; macOS binaries are not Developer ID signed or notarized. Linux/macOS 32-bit, Linux ARM64, Alpine/musl, and Windows ARM64 binaries are not supplied. Python 3.11+ wheel and source packages are included; no PyPI publication. `SHA256SUMS` covers all seven packages.

```bash
./netspector scan ./project --format html --output report.html
./netspector scan ./examples/network-map --format html --output example.html
```

### 한국어

HTML 기본 화면을 프로젝트별 네트워크 구성도로 개선했습니다. 서버·게이트웨이·컨테이너 아이콘과 영역, 직각 연결선, 프로토콜·포트 라벨을 제공하며 동일 호스트는 하나의 노드로 합칩니다. 방향별 연결은 중복 제거하되 모든 근거를 보존합니다.

노드 드래그·방향키 이동, 배치 초기화, 확대/축소, 프로젝트·검색·방향 필터와 SVG 저장을 지원합니다. 수동 배치는 현재 페이지에서 유지되고 SVG로 보관할 수 있습니다. 자세한 목록은 접어서 표시하고 클릭하면 원본 출처를 확인할 수 있습니다.

Linux x64, macOS Intel·Apple Silicon, Windows x64·32비트 x86 패키지를 제공합니다. Windows 32비트는 WOW64에서 검증하며 Windows 10 실기기 검증은 아직입니다. 아이콘은 논리적 역할이며 실제 물리 장비나 트래픽을 탐지한 결과는 아닙니다.

## netspector v0.1.0

First public release: discover network intent from Python source, Kubernetes manifests, and configuration files.

### Highlights

- FastAPI routes and requests/httpx outbound calls with source evidence.
- Scoped constant resolution and environment URL candidates from dotenv, Kubernetes env, and ConfigMap references.
- Declared Kubernetes ports and Ingress paths; JSON/YAML/TOML URL discovery.
- Table, JSON, and CSV reports; exclusions, redacted URL credentials/query values, and partial-scan diagnostics.
- English and Korean documentation.

### Downloads

Standalone packages include the runtime: **no Python installation required**. Extract the entire archive and run `netspector` (`netspector.exe` on Windows).

| Platform | Asset | Compatibility / verification |
| --- | --- | --- |
| Linux x64 | `netspector-0.1.0-linux-x86_64.tar.gz` | Ubuntu 22.04+ / glibc 2.35+ target; built and smoke-tested on Ubuntu 22.04 |
| macOS Intel | `netspector-0.1.0-macos-x86_64.tar.gz` | macOS 15+ target; built and smoke-tested on macOS 15 Intel |
| macOS Apple Silicon | `netspector-0.1.0-macos-arm64.tar.gz` | macOS 15+ target; built and smoke-tested on macOS 15 ARM64 |
| Windows 10/11 x64 | `netspector-0.1.0-windows-x86_64.zip` | Windows 10/11 compatibility target; built and smoke-tested on Windows Server 2022, not a Windows 10 device |

Windows executables are unsigned; macOS executables are ad-hoc signed by the packager, not Developer ID signed or notarized. OS download protections may require approval. Native Windows 10 verification is still pending. Linux ARM64, Alpine/musl, Windows ARM64, and 32-bit binaries are not included.

`SHA256SUMS` covers all downloadable packages. A Python wheel and source distribution are also included for Python 3.11+ users; there is no PyPI publication in this release.

### Quick start

Linux / macOS:

```bash
./netspector --version
./netspector scan ./examples/demo
./netspector scan /path/to/project --format json --output connections.json
```

Windows PowerShell:

```powershell
.\netspector.exe --version
.\netspector.exe scan .\examples\demo
.\netspector.exe scan C:\path\to\project --format json --output connections.json
```

### Scope

Static findings describe declarations, not observed traffic. Environment matches remain candidates because source-to-deployment association is not established. Helm templates, Terraform, Secrets, and whole-program data flow are not supported yet.

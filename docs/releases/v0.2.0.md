## netspector v0.2.0

Adds Java/Spring analysis, Kubernetes network paths, offline HTML reports, and broader configuration discovery to every standalone package.

### New capabilities

- Java: direct Spring controller mappings, typed RestTemplate calls, JDK HttpRequest URI declarations, constants, getenv, and @Value candidates. No JDK is required.
- Kubernetes: Ingress → Service → workload → container paths, named/numeric targetPort matching, provenance, and explicit partial/unresolved results.
- Offline HTML reports with search, direction filters, expandable evidence, and diagnostics.
- XML: Spring property/map values, generic URL text/attributes, web.xml context/init parameters and servlet mappings. DTDs and entities are rejected before expansion.
- INI: sections, DEFAULT inheritance, literal percent values, and source lines.
- Configuration: bounded `${NAME}` resolution and sibling host/port/scheme/path combinations across properties, dotenv, JSON, YAML, TOML, INI, and XML. Environment variants remain separate candidates; each variant uses at most one external document. No runtime environment, code execution, or endpoint requests.
- English and Korean documentation, runnable configuration examples, and extracted-binary checks for Java, configuration, topology, HTML, Unicode paths, and error handling.

### Output compatibility

JSON retains `schema_version: "1"` and adds `connections`. CSV adds `record_type` and `connection`; filter `record_type=finding` for endpoint-only rows. Configuration groups use the new `configuration-endpoint` kind. Configuration candidates do not establish actual traffic or direction. Duplicate configuration keys are not silently selected; unresolved templates stay dynamic. URL credentials, queries, and fragments are removed.

Python is bundled in standalone archives. Native Windows 10 device testing is pending; WOW64 testing does not establish native 32-bit OS compatibility. Windows binaries are unsigned; macOS binaries are not Developer ID signed or notarized. Linux/macOS 32-bit, Linux ARM64, Alpine/musl, and Windows ARM64 binaries are not provided. A Python 3.11+ wheel and source distribution are included; this is not a PyPI publication. `SHA256SUMS` covers all seven packages.

```bash
./netspector scan ./project --format html --output report.html
./netspector scan ./examples/config --format json
```

### Limits

Java remains bounded static analysis, not whole-program resolution; WebClient/Feign and Spring Batch-specific job/step semantics are not modeled. Raw Helm templates, Terraform `.tf`, Jenkinsfile, and generic `.conf` are not newly supported. Rendered Helm YAML works through the Kubernetes reader. Configuration profile precedence, default placeholders, shell expansion, XML bean references/imports, and Kubernetes `$(VAR)` evaluation remain unsupported. See the README for exact analysis and expansion limits.

### 한국어

Java·Spring 분석, Kubernetes 연결 경로, 검색 가능한 오프라인 HTML 보고서와 XML·INI 설정 분석을 실행 파일에 포함했습니다. `${NAME}` 설정 참조와 분리된 host/port/scheme/path를 해석하며, 환경별 후보와 출처를 보존합니다. XML 외부 엔티티·DTD는 차단하고 대상 코드나 셸을 실행하지 않습니다.

Linux x64, macOS Intel·Apple Silicon, Windows x64·x86의 다섯 가지 패키지를 제공합니다. Windows 32비트는 `windows-x86.zip`을 선택하세요. 32비트 Python과 PE32/I386 및 WOW64 실행을 검증하며, Windows 10 실기기 검증은 아직 진행하지 않았습니다.

CSV에 `record_type`·`connection` 열이 추가됩니다. 기존 엔드포인트만 필요하면 `record_type=finding`으로 필터링하세요. Spring Batch 전용 분석, WebClient·Feign, Terraform·Jenkinsfile·원본 Helm 템플릿·일반 conf 분석은 이번 범위에 포함되지 않습니다.

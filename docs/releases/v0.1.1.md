## netspector v0.1.1

Adds a standalone **Windows 10 x86 (32-bit)** package while retaining all four 64-bit packages from v0.1.0. Python installation is not required.

### What's changed

- Dedicated x86 Python build and Python 3.11–3.13 x86 CI jobs.
- Interpreter pointer-width checks prevent accidental 64-bit builds under a 32-bit filename.
- Windows PE Machine and Optional Header checks verify PE32/I386 for x86 and PE32+/AMD64 for x64, before packaging and after archive extraction.
- Extracted binaries are exercised outside the source checkout: demo scanning, environment candidates, Unicode paths, JSON/CSV/table output, and error exit codes.
- Updated English/Korean download instructions and build metadata.

### Downloads

| Platform | Asset | Compatibility / verification |
| --- | --- | --- |
| Windows 10 x86 (32-bit) | `netspector-0.1.1-windows-x86.zip` | Built with 32-bit Python; PE32/I386 verified; executed via WOW64 on Windows Server 2022 |
| Windows 10/11 x64 | `netspector-0.1.1-windows-x86_64.zip` | Built and smoke-tested on Windows Server 2022 |
| Linux x64 | `netspector-0.1.1-linux-x86_64.tar.gz` | Ubuntu 22.04+ / glibc 2.35+ target; tested on Ubuntu 22.04 |
| macOS Intel | `netspector-0.1.1-macos-x86_64.tar.gz` | macOS 15+ target; tested on macOS 15 Intel |
| macOS Apple Silicon | `netspector-0.1.1-macos-arm64.tar.gz` | macOS 15+ target; tested on macOS 15 ARM64 |

For **32-bit Windows**, download `windows-x86.zip`, not `windows-x86_64.zip`. Native Windows 10 32-bit device testing is pending; WOW64 testing on a 64-bit server is not equivalent to testing a 32-bit OS. Windows executables remain unsigned; macOS executables are not Developer ID signed or notarized.

Linux/macOS 32-bit, Linux ARM64, Alpine/musl, and Windows ARM64 binaries are not included. A wheel and source distribution are available for Python 3.11+; this release does not publish to PyPI. `SHA256SUMS` covers all seven packages.

### Windows quick start

Extract the ZIP, open PowerShell in the extracted directory, and run:

```powershell
.\netspector.exe --version
.\netspector.exe scan .\examples\demo
.\netspector.exe scan C:\path\to\project --format json --output connections.json
```

Static analysis capabilities are unchanged from v0.1.0. Environment matches remain candidates, not proof of a deployed connection.

### 한국어

**Windows 10 32비트(x86) 실행 파일을 추가했습니다.** Python 설치 없이 압축을 풀어 실행할 수 있습니다. 32비트 Windows에서는 `netspector-0.1.1-windows-x86.zip`을 선택하세요. 기존 Windows x64·Linux x64·macOS Intel 및 Apple Silicon 패키지도 제공합니다.

32비트 Python 빌드, 실행 파일 PE32/I386 헤더, 압축 해제 후 실제 실행을 검증합니다. 자동 실행 검증 환경은 Windows Server 2022의 WOW64이며, Windows 10 32비트 실기기 검증은 아직 진행하지 않았습니다. Linux/macOS의 32비트 실행 파일 지원은 이번 릴리스에 포함되지 않습니다.
